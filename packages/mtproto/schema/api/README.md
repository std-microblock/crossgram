# Telegram API schema mirror

This directory is generated by `pnpm schema:sync` from
`https://core.telegram.org/schema`.

- `manifest.json` records the requested/reported layer, SHA-256, and raw size.
- `layer-*.tl` contains the exact plain TL text extracted from
  `pre.page_scheme > code` for every historical layer currently advertised by
  Telegram.
- Telegram advertises layer 1 but currently returns layer 223 for that request;
  the manifest records it as unavailable instead of storing incorrect data.

Do not edit generated schema snapshots manually. The MTProto runtime validates
their SHA-256 and uses `@mtcute/tl-utils` to code-generate historical readers
and writers directly from these readable files.
